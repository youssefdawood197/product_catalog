# Product Catalog (Flutter Assessment)

A mini app demonstrating clean architecture, Cubit state management, go_router navigation, get_it DI, responsive UI via flutter_screenutil, and English/Arabic i18n.

## Requirements covered
- Clean architecture — Data / Logic (Cubit) / UI
- go_router for navigation
- get_it for DI
- flutter_screenutil for responsiveness
- Android & iOS support
- EN/AR internationalization + toggle
- Splash, 2-step onboarding (skip), Product list, Product details

## Getting started
```bash
flutter pub get
flutter run
```
